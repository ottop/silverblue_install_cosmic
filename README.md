# Install Cosmic on Fedora Silverblue

This is a simple script to install the Cosmic desktop on Fedora Silverblue. It installs all of the Cosmic-related packages that come up when running `rpm-ostree search cosmic`.

## Usage
1. Clone the repository: `git clone git@github.com:ottop/silverblue_install_cosmic.git`
2. Enter the directory: `cd silverblue_install_cosmic`
3. Give the script the permission to run: `chmod +x install_cosmic.sh`
4. Run the script: `./install_cosmic.sh`
